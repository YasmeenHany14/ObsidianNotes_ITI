# View port
* vh, vw
* Relative to current screen size, completely ignoring parent size
* 50vw => 50% of the current screen width

# REM / EM
## EM
* Relative to parent font size
* 1em is equal to the font size value of the parent element


## REM
* rem stands for root em 
* Relative to HTML font size
* 1rem is equal to the font size value of the html font size

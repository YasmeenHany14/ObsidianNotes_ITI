- Inside the HEAD elements there are 6 key elements that are used regularly
## Meta
- `</meta>`
1. Data about data (How to render this page?)
2. Self-closing (No closing tag)
3. Contains Attributes
	- charset
		- Characters the website support
	- name=””
	- description=””
		- Both shows in search engines

## Style
- `<style> </style>`
- CSS code inside
## Script
- `<script>`
- JS code inside
## Link
- Link pages
- `<link rel=”stylesheet” type=”text/css” href=”main.css”/>`
- rel means what is the relation of that link to the document
## Title
- `<title> HTML Fundamentals </title>`
- Title of the page appearing on the tab name
### Base
- Allows us to specify a base address that all other documents will be based on.

## Default argument 
* any parameter set with a default value is called an optional parameters, the others are required parameters
* optional parameters should always be declared at the end of the params, or compile error
``` cpp
int Add(int x, int y, int z) {
	return x + y + z;
}

int Add2(int x=2, int y, int z);

int Add3(int x, int y = 0; int z = 0) {}

int Add4(int x = 0, int y = 0; int z = 0);
int Add4(int x, int y);

Add4(1, 2); // compile error, ambiguty
			// compiler doesn't know which one to execute because two functions can be called with this number of arguments even if their signatures are different

```

## Destructor
* Special function called inside struct/class at end of life to clean up
* Cannot be overloaded
* Cannot be called
* Must be public
* Always generated by compiler by default and empty
#### Why use it?
1. Connect to database and clean up this connection
2. Read/write in file
3. Dynamic allocation

``` cpp
~ Complex {
	// write destruction code here	
}

class Draft {
	int *ptr;
	Draft() {
		ptr = new int[5];
	}
	~Draft {
		delete[] ptr;
	}
}

void Tryme() {
	Draft d;
}

Tryme();
Tryme();
Tryme();
// without destructor cleaning up, this will be a memory leak

```

## Datastructures
 * Stack
 * FILO

``` cpp
template <typename T>
class Stack {
	int sz;
	int tos;
	T *stack;
	
	public:
	inline static int cnt = 0;
	Stack() {
		sz = 2;
		stack = new T*[sz];
		tos = -1;
		cnt++;
	}
	
	Stack(int _sz) : Stack(){
		sz = _sz;
	}
	
	void Push(T x) {
		if(tos == sz - 1)
			IncreaseSize();
		stack[++tos] = x;
	}
	
	T Pop() {
		return stack[tos--];
	}
	
	bool IsEmpty() {
		return tos == -1;
	}
	
	private:
	void IncreaseSize() {
		T* newStack = new T[sz * 2];
		for(int i = 0; i < sz; i++)
			newStack[i] = stack[i];
		T* ptr = stack;
		stack = newStack;
		delete[] ptr;
	}
	
	friend void PrintStack(Stack stk);
	
	~Stack{
		// madatory in lab => 
		for(int i = 0 ;i < sz; i++)
			stack[i] = -1;

		delete[] stack;
		cnt--;
	}
};

// friend function 
// friend function can access private fields of a class
void PrintStack(Stack stk) {
	for(int i = tos; i >= 0; i--)
		cout << stk.stack[i] << '\n';
}
cout << Stack::cnt; // works
cout << s1.cnt; // works but not recommended for readability
```

### Static variables
* Belong to class not instance
* One copy in memory
* Should be initialized with initial value (mandatory) using inline keyword
* If i wanna initialize outside, it's done before main, why?
	* using same header file multiple times in the same program will result in static vars being initialized more than once = compiler error
* Giving initial value in declaration like normal vars is not allowed (compile error)

## Object oriented relations
### Composition
* Tightly coupled
* Permenent relationship and complete ownership
* Walls result in having a room, breaking one wall will destroy room
* Object of class inside another class

### Aggregation
* Loosely coupled
* Same as association, but a bit more coupled than associated
* Whole vs part (student belongs to one department)
* Represented same way as association
* Diff between aggregation and association:
	Business difference, 

### Association
* Very loosely coupled
* Peer to peer relationship (teacher with subject)
* Temporarily relation, are associated together for a specific reason, and separating them doesn't affect any of the entities
* Represented by having a pointer of class in the other class
* No dependency between them
### Inheritance
* Complete dependency
